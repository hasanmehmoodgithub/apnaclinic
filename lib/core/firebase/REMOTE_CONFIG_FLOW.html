Fail defaults

      

        
EventWhat the app uses

        
          
Firebase init failsFlavor production URL. Skip Remote Config.

          
Fetch timeout / offlineLast-good if present, else flavor URL.

          
Empty / non-HTTPS / unknown hostReject. Last-good, then flavor URL.

          
Spark throttleNo new template. Cached / default keep working.

          
Host would change mid-sessionPersist for next cold start (HMAC stays on one host).

        
      

      
Roll out a console URL change 10% → 50% → 100%. A bad host can break login for every production user.

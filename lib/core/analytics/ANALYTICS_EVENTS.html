Apna Clinic analytics events

Firebase → GA4 Mobile Property only. Meta App Events and TikTok App Events are not sent. Generated from the Flutter app as of 22 Aug 2026.

How this works (dev)

  • Every event goes through AnalyticsService.logEvent → FirebaseAnalyticsProvider → Firebase Analytics / GA4.
  • Names live in lib/core/analytics/analytics_event_keys.dart. Feature helpers: ConsultationAnalytics, LabTestAnalytics, SurgeryAnalytics, BookingsAnalytics, plus cubit methods for pharmacy / Instant Doctor / auth.
  • Debug: each call also writes developer.log named AnalyticsService (Xcode / Logcat / Flutter console).
  • Events before Firebase init are dropped.
  • Meta / TikTok keys (fb_content_type, content_type) are not sent. Some events send af_content_type on Firebase only.
  • MSISDN is digits-only, 92 / leading 0 stripped (e.g. 3012345678).

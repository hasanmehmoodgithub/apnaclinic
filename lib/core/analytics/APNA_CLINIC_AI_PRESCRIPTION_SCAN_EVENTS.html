Firebase / GA4 event keys

Product reference for Care Companion AI (Noor chat) and Pharmacy prescription scan. Event names are snake_case, ≤40 characters. Production builds send to Firebase; non-prod logs locally.

Notes for product

  • Care Companion AI keys are separate from consultation AI screening events ai_chat_started / ai_chat_ended (WebView).
  • Guest values use Yes / No (same as other app events).
  • Date: 30 Oct 2026 · App module: Flutter Apna Clinic

1. Care Companion AI

Screen: Apna Clinic AI chat (ApnaClinicAiScreen). Entry today: home floating bot (source home_fab).

Events

Event name When it fires Parameters
apna_clinic_ai_opened User opens Care Companion chat source, guest
apna_clinic_ai_closed User leaves chat (back / dispose) source, guest
apna_clinic_ai_message_sent User sends a text message or a voice turn is submitted channel, guest, optional conversation_id
apna_clinic_ai_message_received Assistant final reply arrives for that turn channel, guest, optional intent, turn_id, conversation_id
apna_clinic_ai_voice_started Mic recording starts successfully guest
apna_clinic_ai_voice_sent Voice note is sent to the AI (after stop/send) guest
apna_clinic_ai_voice_cancelled User cancels / deletes in-progress voice recording guest

Parameter values

Param Allowed values Meaning
source home_fab, dashboard_menu, unknown Where the chat was opened from
channel text, voice How the user sent the turn
guest Yes, No Whether the user is a guest
intent e.g. ADD_TO_CART, BOOK_CONSULTATION, PHARMACY_CHECKOUT Server intent on the final reply (when present)
conversation_id string AI conversation id when known
turn_id string AI turn id on received final (when present)

Typical funnel

opened → message_sent / voice_started → voice_sent → message_received → closed

2. Pharmacy prescription scan

Screen: Scan prescription (PrescriptionScanScreen). Keys follow the same app snake_case style as other pharmacy events.

Events

Event name When it fires Parameters
pharmacy_prescription_scan_opened User opens the scan screen source (default home)
pharmacy_prescription_scan_closed User leaves the scan screen source
pharmacy_prescription_scan_source_selected User chooses Camera or Gallery pick_source
pharmacy_prescription_scan_picked User successfully picks an image pick_source
pharmacy_prescription_scan_started Extract / OCR API call starts —
pharmacy_prescription_scan_success Extract succeeds medicine_count
pharmacy_prescription_scan_failed Extract fails optional error_code
pharmacy_prescription_scan_medicine_added Matched medicine added to cart from scan results product_id, product_name, source

Parameter values

Param Allowed values Meaning
source home, search, banner (pharmacy source set) Pharmacy entry context (scan currently logs home)
pick_source camera, gallery How the prescription image was chosen
medicine_count number Medicines returned by extract
error_code string App/server failure code when extract fails
product_id / product_name string Catalog medicine added from scan

Typical funnel

opened → source_selected → picked → started → success / failed → medicine_added → closed

Out of scope on this sheet

  • Full pharmacy / consultancy / lab / surgery event catalogue (see existing app analytics HTML if needed).
  • AppsFlyer-only events.
  • Consultation AI screening WebView (ai_chat_started / ai_chat_ended).

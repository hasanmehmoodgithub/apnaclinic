Apna Clinic AppsFlyer events

Separate from Firebase. One AppsFlyer name can cover several user actions. The filled parameter is what tells them apart. Generated from the Flutter app as of 5 Oct 2026.

How to read this

  • AppsFlyer is not a copy of Firebase. Firebase keeps a different event name per action. AppsFlyer often reuses one name and changes the parameters.
  • Calls go through AppsFlyerService.logEvent. Names live in lib/core/services/appsflyer_event_keys.dart.
  • If the SDK has not started (missing Dev Key, or missing iOS App ID), logEvent does nothing.
  • MSISDN is digits only, with country code 92 or a leading 0 removed (example 3012345678).
  • Timestamps use M/D/YYYY H:mm (example 10/5/2026 12:58).

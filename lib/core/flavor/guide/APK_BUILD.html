How Chucker is gated

Default in releaseCHUCKER_ACTIVE=true — inspector is on unless you opt out
Turn off--dart-define=CHUCKER_ACTIVE=false
Debug buildsChucker is always on in debug, even if the flag is false
Store APKUse production + CHUCKER_ACTIVE=false
  • flutter run -d android / -d ios uses a connected device or simulator. flutter build apk is a release APK. Flavor defaults to development if APP_FLAVOR is omitted.
  • SecurityGate is on by default. Skip with --dart-define=SECURITY_CHECKS=false (internal/QA only — do not ship store builds this way).
  • iOS: flutter build ios → Runner.app. flutter build ipa → build/ios/ipa/ for TestFlight / App Store.
  • Fat APK default: app-release.apk. With stamp on, it is renamed to apnaclinic-staging-chucker-YYYYMMDD-HHMM.apk.
  • --build-name is Android versionName (Settings). --build-number is versionCode (integer, unique per minute). Store/Play builds should keep a normal 1.x.y name.

Mock configuration summary

Flag Default Affects
enableAuthMocks false OTP, logout
enableProfileMocks false Profile get / save
enableDashboardMocks false Services, promotional banner
enableConsultationMocks false Categories, doctors list
enableSurgeryMocks false Surgery list, providers, patient form, booking mocks
enableMocks true (hardcoded) Pharmacy, search, notifications, free doctor, customer support, lab catalog, account
Tip: To exercise real APIs for mock-gated features, set enableMocks to respect MOCKTRUE / debug instead of always returning true in lib/core/config/mock_config.dart.
